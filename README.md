### ⚙️ Automation Pipeline
> 수동 작업을 최소화하고 안정적인 배포 및 모니터링을 위해 설계된 파이프라인입니다.

* **Step 1. Scheduling:** `Claude Code Schedule Skill`을 통해 매일 오전 9시와 정오 12시에 자동 트리거를 발생시킵니다.
* **Step 2. Workflow:** `GitHub Actions`를 통해 코드 검사 및 빌드 워크플로우를 실행합니다.
* **Step 3. Execution:** `Cron` 이벤트 감지 시스템이 특정 시점의 작업을 정밀하게 수행합니다.
* **Step 4. Monitoring:** 모든 프로세스의 성과 및 상태를 `Slack Webhook`으로 실시간 수신하여 관리합니다.
