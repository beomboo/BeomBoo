## 🎮 Current Project : 모바일 방치형 게임
> AI와 자동화 파이프라인이 결합된 차세대 모바일 방치형 게임을 개발하고 있습니다. 2D 픽셀 아트 디자인과 세밀한 스프라이트 애니메이션 로직 구현에 집중하고 있습니다.

### 💡 Core Technologies
- **Game Engine & Language :** Flame, Dart (Flutter)
- **IDE :** Antigravity, Visual Studio Code
- **AI Models :** Gemini 3.1 Pro, Gemini 3 Flash, Claude Code Sonnet 4.6
- **MCP :** Firebase, Flame, Github

### ⚙️ Automation Pipeline Architecture
안정적인 게임 서비스와 성능 분석을 위해 아래와 같은 자동화 프로세스를 구축하여 운용 중입니다.

1. 🕒 **Claude Code Schedule Skill:** 매일 오전 9시, 정오 12시에 자동 트리거되는 스케줄러 작동
2. 🔄 **GitHub Actions:** 지속적 통합/배포(CI/CD) 워크플로우 수행
3. ⚡ **Cron Event Detection:** 특정 크론 이벤트 감지 후 백그라운드 작업 수행
4. 💬 **Slack Webhook Integration:** 성능 분석 시작 및 완료 시 실시간 알림 메시지 수신
