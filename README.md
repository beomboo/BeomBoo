## 🎮 진행 중인 프로젝트 : 모바일 방치형 게임
> AI와 자동화 파이프라인이 결합된 모바일 방치형 게임을 개발하고 있습니다. Flame 엔진을 활용한 픽셀 아트 스프라이트 애니메이션 구현에 집중하고 있으며, 안정적인 안드로이드 빌드 및 앱 서명(Keystore/SHA-256) 관리를 포함한 배포 자동화를 함께 구축해 나가고 있습니다.

### 💡 핵심 기술
- **게임 엔진 및 언어 :** Flame, Dart (Flutter)
- **개발 환경 (IDE) :** Antigravity, Visual Studio Code
- **AI 모델 :** Gemini 3.1 Pro, Gemini 3 Flash, Claude Code Sonnet 4.6
- **MCP (통합 관리) :** Firebase, Flame, Github

### ⚙️ 자동화 파이프라인 프로세스
안정적인 게임 서비스 운영과 성능 분석을 위해 아래와 같은 자동화 프로세스를 운용 중입니다.

1. 🕒 **Claude Code Schedule Skill :** 매일 오전 9시, 정오 12시 자동 트리거 스케줄러 작동
2. 🔄 **GitHub Actions :** 지속적 통합 및 배포(CI/CD) 워크플로우 수행
3. ⚡ **Cron 이벤트 감지 :** 특정 크론 이벤트 감지 후 백그라운드 작업 수행
4. 💬 **Slack Webhook :** 성능 분석 시작 및 완료 시 실시간 알림 메시지 수신
